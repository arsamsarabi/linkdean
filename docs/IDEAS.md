## improved social features

Explore these possibilities and evolve these features into a full social features system.
- add a way to "like" a bookmark
- add a way to "bookmark" a bookmark
- add a way to "share" a bookmark
- add a way to "comment" on a bookmark
- add a way to "follow" a user
- add a way to "unfollow" a user
- add a way to "block" a user
- add a way to "unblock" a user
- add a way to "mute" a user
- add a way to "unmute" a user
- Add config option so a user can control visibility of their profile and bookmarks/lists (public, private, followers only, etc.) hidden profile and private bookmarks/lists

## sharing features rework

When an items is shared with the user, instead of immediately display the items in the users account, display a notification in the users account that they have been shared with. The user can then click accept to add the items to their account, or reject to ignore the shared items.
