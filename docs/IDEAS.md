## Future Enhancements

### Enable API key authentication for users

Users of the app should be able to create API keys which should allow them access to their own data programmatically. 

Admins should be able to switch this setting on and off for individual users, and the platform as a whole.

### Dashboard

A dashboard for users create a sectioned grid of a selection of their bookmarks. The idea is to have something similar to my Authentik/Glance dashboards. Where users can arrange their frequesntly visited bookmarks with ease.

Once we have implemented shared folders/lists we should also add shared dashboards. And enable the creator of the dashboard to control access of the invitees (read only/ read write).
