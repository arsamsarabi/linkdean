# Linkdean logo guidelines (compact)

## 1. The logo
- **Idea:** Two open chain-links mid-interlock (saving a link as a snap).
- **Versions:** primary horizontal · stacked · symbol-only · wordmark-only
- **Files:** `brand/final/` masters · `brand/exports/` delivery variants · `brand/exports/web/` favicons/PWA

Wordmark uses **Rajdhani Bold** outlines (same family as app headings). Body UI stays Satoshi.

## 2. Clear space
Keep a clear zone of **1 × link thickness** (approximately the stroke width of one chain ring) around the logo on all sides. Scales with the logo.

## 3. Minimum size
| Version | Screen | Print |
|---|---|---|
| Horizontal | 120 px wide | 30 mm wide |
| Symbol | 24 px (use `linkdean-symbol-small` / favicon below 32 px) | 8 mm |
| Favicon | 16 px (`favicon.svg` / `favicon.ico`) | n/a |

## 4. Colour
| Name | HEX | RGB | Role |
|---|---|---|---|
| Purple Pain | `#8458B3` | 132, 88, 179 | Primary logo / app icon tile |
| Ice Cold | `#A0D2EB` | 160, 210, 235 | Accent mono / links in UI |
| Freeze Purple | `#E5EAF5` | 229, 234, 245 | Light surfaces |
| Heavy Purple | `#A28089` | 162, 128, 137 | Muted / borders |
| Night | `#1A1618` | 26, 22, 24 | Dark surfaces |

**Approved pairs:** colour on Freeze/white · white on Purple Pain · white on Night · black on white.
Never put Purple Pain mark on Ice Cold (low contrast).

## 5. Typography
- Logo wordmark: Rajdhani Bold (outlined in masters)
- Headlines: Rajdhani · Body: Satoshi
- Do not recreate the wordmark by typing; use the SVG masters

## 6. Don'ts
Don't stretch or squash · don't recolour outside the palette · don't rotate the lockup · don't add shadows/outlines/gradients · don't rearrange symbol + type spacing · don't use the full-detail symbol below 24 px (use small cut)

## 7. Masters
`brand/final/` · web set `brand/exports/web/`
Trademark clearance not included; run a professional search before public launch.
