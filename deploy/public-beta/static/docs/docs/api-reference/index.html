API reference

Every endpoint of the Linkdean HTTP API (version 0.0.9), generated from the routes. The same description as an OpenAPI 3.1 document: openapi.json. A running instance also serves its own copy at /api/openapi.json.

Basics​

  • Base URL: https://<your instance>/api, for example https://app.linkdean.app/api.
  • Authentication: send an API key (create one under Config options → API keys) as Authorization: Bearer ldk_…. Endpoints marked sign-in session only refuse API keys, so a leaked key cannot mint more keys or use admin powers.
  • Errors: every error has the same JSON body, { "code": "not_found", "message": "not found", "details": { … }, "error": "not found" }. Match on code, show message. details appears only for some codes (banned, quota_exceeded, vault_move_blocked). error repeats message for older clients.
  • Caching: successful JSON reads carry an ETag and Cache-Control: private, no-cache. Send the tag back in If-None-Match to get 304 Not Modified with no body.
  • Rate limits: sign-in, registration and some writes answer 429 with code too_many_requests when called too often.
  • Request IDs: every response has an X-Request-Id. Send your own (letters, digits, _, -, ., up to 128) to follow a request through the server logs and traces.

Error codes​

CodeStatusMeaning
bad_request400The input was refused; message says why.
invalid_body422The JSON body did not match the expected fields.
unauthorized401Wrong password, or no credentials where they are needed.
session_expired401The session or API key is missing, expired or revoked.
forbidden403Signed in, but not allowed.
banned403The account is banned; details.ban has the reason and end.
email_unverified403The instance requires a verified email address first.
quota_exceeded403details has meter, limit and used.
not_found404No such thing, or not visible to you.
method_not_allowed405The path exists with other methods.
conflict409Already exists or changed meanwhile.
vault_move_blocked409details.blockers lists what to undo first.
payload_too_large413The upload is over the limit.
unsupported_media_type415Send Content-Type: application/json.
vault_locked423Unlock the vault first.
vault_unlock_failed401Wrong vault passphrase.
too_many_requests429Slow down and retry later.
internal500Server error; quote the X-Request-Id.

GET /auth/oidc/start​

?mode=connect attaches the provider identity to the signed-in account instead of signing in; it needs a session. Sign-in may create an account, so it needs ?terms_version= equal to the current terms version; the flow cookie carries it to the callback, which records it on a new account. Existing accounts sign in unchanged. Connect mode never creates an account.

Auth: API key or sign-in session (bearer token or cookie).

ParameterInTypeRequiredNotes

terms_versionquerystring
providerquerystringoidc, google, microsoft or github; the first configured one when unset.
