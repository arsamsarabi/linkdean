Public beta and feedback

Linkdean is in public beta at app.linkdean.app. Thank you for trying it.

What the beta means​

  • It is free. No card, no trial clock. Plans for a paid managed service are still being worked out; see the roadmap.
  • No uptime promise. The beta runs on a single server with monitoring and off-site backups that are restored in a test drill, but it can go down. Export your library from Config options → Import / Export now and then.
  • Things change. Features move, and the occasional bug gets through. Releases are listed in the changelog.
  • Your data is yours. Exports are complete and import into another Linkdean, and the app is source-available, so you can run your own. How data is handled: Privacy Policy.

Feedback​

  • Something broke? Open a bug report on GitHub. Say what you did, what you expected and what happened, plus your browser and device. A screenshot helps. Leave out anything private, such as the addresses of your bookmarks.
  • An idea or a question? Start a thread in GitHub Discussions.
  • No GitHub account, or something private? Email contact@linkdean.app.
  • A security problem? Do not open a public issue. Follow the security policy.

Most useful to test right now​

  • Importing your real bookmarks from a browser, Pocket or Raindrop.
  • Saving pages with the browser extension or the bookmarklet.
  • Using it on a phone: saving from the share sheet, filing Unsorted bookmarks.
  • Sharing a folder with a friend.
