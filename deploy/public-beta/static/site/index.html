Encrypted vaults for private links

Each vault has its own passphrase and recovery key. Its links are encrypted at rest and never reach the search index.

Unlocking opens a vault for one session only. Other devices and API keys stay locked.

Questions about Linkdean

Is Linkdean free?

Yes, while the public beta runs. Self-hosting costs nothing beyond your own server.

Can I bring my bookmarks?

Import browser HTML, Pocket CSV, Raindrop CSV or a Linkdean export. Export HTML or JSON whenever you like.

Who can open my vaults?

Only you, with the vault's passphrase or recovery key. Lose both and the contents are gone, for us too.

Does it work on my phone?

Install it from the browser as an app, with tabs for home, library, add and search.
